# mrg-join-ad-keytab

Ansible role for RHEL 8/9/10 servers to configure OUD+AD coexistence and
join Active Directory. Replaces `pnc_join_ad` and `pnc_auth_config` RPMs.
Builds the AD bind keytab at runtime using the bind account password.

---

## Layout

```
mrg-join-ad-keytab/
  files/        static config files, Jinja2 templates, rbin scripts
  meta/         main.yml (placeholder only)
  playbooks/    main.yml (AAP entry point)
  tasks/        all task logic, entry point is tasks/main.yml
  vars/         main.yml (all role variables)
  README.md
```

---

## vs. pnc\_join\_ad and pnc\_auth\_config RPMs

| | RPMs | This role |
|---|---|---|
| sssd.conf | Generated by `amm-create-authn` on jumpbox, installed by `pnc_auth_config` | Generated at runtime from `files/sssd.conf.j2` via `tasks/generate_oud_config.yml` |
| OUD hostId account | Created by `amm-create-authn` (run manually on jumpbox) | Created automatically on the target host via `ldapmodify` — no jumpbox dependency |
| AD bind keytab | Pre-built static file installed by RPM | Built at runtime via `adcli join --stdin-password` using the bind account password |
| AD join | `pnc_join_ad` RPM `%post` | `tasks/join_ad.yml` via `adcli` |
| conf.d files | Shipped inside RPM | `files/50-pncad.conf.j2`, `55-pncad.conf.j2`, `60-pnc-OUD-AD.conf.j2` |
| krb5.conf | Shipped inside RPM | `files/krb5.conf.j2` |
| rbin scripts | `/usr/local/pnc/rbin/` from RPM | `files/rbin/` — same scripts |
| login-access.conf | Populated by `pnc-run-discovery` in RPM `%post` | Same — `pnc-run-discovery` called in `tasks/configure_auth.yml` |
| Home dir management | RPM `%post`/`%preun` shell loop, UID range 2000000-100000000 | Same UID range, `tasks/manage_homedirs.yml` |
| Decommission | `rpm -e` | `dual_auth_lifecycle_action=leave_ad` |

## Lifecycle actions

Set via `-e` on CLI or AAP Survey (single-select). Default: `configure`.

| Action | OUD+AD host | Legacy AD-only host |
|---|---|---|
| `configure` | Reapply full config | Set up OUD+AD dual auth (new build) |
| `rejoin` | Leave AD + rejoin as OUD+AD | Leave AD + rejoin as AD-only |
| `leave_ad` | Full decommission | Leave AD |
| `convert_ad_only` | Convert to AD-only | Warn + skip (already AD-only) |
| `recreate_keytab` | Rebuild machine keytab via `adcli join` | Same |
| `recreate_sssd` | Regenerate `sssd.conf` with fresh authtok | Warn + skip (no OUD config) |

## Home directory handling

Home dirs are managed by `tasks/manage_homedirs.yml`, which mirrors the
logic from the `pnc_join_ad` RPM `%post`/`%preun`. Only dirs owned by UIDs
in the OUD/AD managed range (`2000000 < uid < 100000000`) are touched —
local accounts are skipped automatically. The role never chowns anything;
sssd corrects ownership automatically once the domain is joined or left.

**`configure` — OUD-only host migrating to OUD+AD**

Existing OUD home dir renamed to free up the path for the AD home dir.
New AD home dir is created by `pam_mkhomedir` on first AD login.

```
Before:  drwx------ sa04192  users                  /home/sa04192
After:   drwx------ sa04192  users                  /home/sa04192OUD
         drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192  (created on login)
```

**`configure` — new build or idempotent rerun**

No home dir action. Both dirs created by `pam_mkhomedir` on first login.

**`leave_ad` — both dirs exist**

AD home dir moved inside the OUD dir for safekeeping.

```
Before:  drwx------ sa04192  users                  /home/sa04192OUD
         drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192
After:   drwx------ sa04192  users                  /home/sa04192OUD
         drwx------ sa04192  users                  /home/sa04192OUD/sa04192AD
         drwx------ 700001166  700001166             /home/sa04192  (numeric - AD gone)
```

**`leave_ad` — only AD dir exists (no OUD counterpart)**

AD dir stays on disk with numeric IDs. sssd corrects ownership on next
`configure` or `rejoin`. No rename, no move.

```
Before:  drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192
After:   drwx------ 700001166  700001166             /home/sa04192
```

**`convert_ad_only`**

OUD home dir moved inside the AD dir as a backup. sssd corrects ownership
of the moved dir to the AD user naturally.

```
Before:  drwx------ sa04192  users                  /home/sa04192OUD
         drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192
After:   drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192
         drwx------ sa04192@uat.pncint.net gslunxpg_sa04192  /home/sa04192/sa04192OUD
```

**`rejoin`, `recreate_keytab`, `recreate_sssd`**

No home dir changes.

## AAP credentials required

**PNC MRG OUD Bind** (custom credential type — request from EAN):

| Field | Description | Secret |
|---|---|---|
| `oud_bind_dn` | OUD admin bind DN (`cn=asc-serviceid,...`) | No |
| `oud_bind_password_rnd` | OUD admin password (RND) | Yes |
| `oud_bind_password_uat` | OUD admin password (UAT) | Yes |
| `oud_bind_password_qa` | OUD admin password (QA) | Yes |
| `oud_bind_password_prod` | OUD admin password (PROD) | Yes |

**PNC MRG AD Bind** (custom credential type — request from EAN):

| Field | Description | Secret |
|---|---|---|
| `ad_bind_username_rnd` | AD bind account (RND) | No |
| `ad_bind_password_rnd` | AD bind password (RND) | Yes |
| `ad_bind_username_uat` | AD bind account (UAT) | No |
| `ad_bind_password_uat` | AD bind password (UAT) | Yes |
| `ad_bind_username_qa` | AD bind account (QA) | No |
| `ad_bind_password_qa` | AD bind password (QA) | Yes |
| `ad_bind_username_prod` | AD bind account (PROD) | No |
| `ad_bind_password_prod` | AD bind password (PROD) | Yes |

Attach both credentials to the AAP Job Template. The role auto-selects the
correct env-specific values based on the detected environment.

## AAP Survey setup

| Question | Type | Variable | Default |
|---|---|---|---|
| Lifecycle action | Single-select | `dual_auth_lifecycle_action` | `configure` |
| Target hosts (one per line) | Textarea | `dynamic_hosts_input` | |

Lifecycle action choices: `configure`, `rejoin`, `leave_ad`, `convert_ad_only`, `recreate_keytab`, `recreate_sssd`

OUD credentials are only needed for new builds (`configure` on a host with no
existing `sssd.conf`) and `recreate_sssd`. Leave blank for all other actions.

## CLI usage

Environment is auto-detected from the 5th character of the hostname.
Override with `-e dual_auth_target_env=<rnd|uat|qa|prod>` if needed.

**New build / reconfigure (default)**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml
```

**Force rejoin AD**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml \
  -e dual_auth_lifecycle_action=rejoin \
  -e ad_bind_password_prod=<password>
```

**Leave AD (full decommission)**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_lifecycle_action=leave_ad
```

**Convert OUD+AD to AD-only**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_lifecycle_action=convert_ad_only
```

**Rebuild machine keytab**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml \
  -e dual_auth_lifecycle_action=recreate_keytab \
  -e ad_bind_password_prod=<password>
```

**Regenerate sssd.conf with fresh authtok**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml \
  -e dual_auth_lifecycle_action=recreate_sssd \
  -e oud_bind_dn="cn=asc-serviceid,ou=TrustedApplications,ou=FrameworkSystems,o=pnc" \
  -e oud_bind_password_prod=<password>
```

**Override environment detection**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_target_env=qa
```

## Host type detection

The role detects the host type automatically during preflight. No manual
flag needed.

| Detected state | Signal | Effect |
|---|---|---|
| OUD-only | `id_provider = ldap` only in sssd config | `configure` renames home dirs before AD join |
| OUD+AD | `id_provider = ldap` + `AUTHMETHOD=OUD+AD` in `PROVISION_CONFIG` | Normal dual auth path |
| Legacy AD-only | `id_provider = ad` without `AUTHMETHOD=OUD+AD` | Adjusted steps per lifecycle action |
