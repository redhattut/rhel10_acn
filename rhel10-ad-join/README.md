# mrg-join-ad-keytab

Ansible role for RHEL 8/9/10 servers to configure OUD+AD coexistence and
join Active Directory. Replaces the `pnc_join_ad` and `pnc_auth_config`
RPMs. Uses a pre-built static keytab file for the AD bind account.

---

## Layout

```
mrg-join-ad-keytab/
  files/        static config files, Jinja2 templates, and keytab files
  meta/         main.yml (placeholder only)
  playbooks/    main.yml (AAP entry point)
  tasks/        all task logic, entry point is tasks/main.yml
  vars/         main.yml (all role variables)
  README.md
```

---

## Keytab files

One keytab file per environment, named with `.dat` to avoid GitHub policy
flags on `.keytab` extensions. Placeholder stubs are in place — replace
with real keytabs before use.

| Environment | File                     | Bind account |
|-------------|--------------------------|--------------|
| rnd         | `files/ad-bind-rnd.dat`  | XAAMMRAS     |
| uat         | `files/ad-bind-uat.dat`  | XAAMMUAS     |
| qa          | `files/ad-bind-qa.dat`   | XAAMMQAS     |
| prod        | `files/ad-bind-prod.dat` | XAAMMPAS     |

Build each with `ktutil`, e.g. for prod:

```
ktutil
addent -password -p XAAMMPAS@PROD.PNCINT.NET -k <kvno> -e aes256-cts-hmac-sha1-96 -s "PROD.PNCINT.NETXAAMMPAS"
addent -password -p XAAMMPAS@PROD.PNCINT.NET -k <kvno> -e aes128-cts-hmac-sha1-96 -s "PROD.PNCINT.NETXAAMMPAS"
wkt ad-bind-prod.dat
quit
```

## vs. pnc\_join\_ad and pnc\_auth\_config RPMs

| | RPMs | This role |
|---|---|---|
| sssd.conf | Generated by `amm-create-authn` on the jumpbox, then installed by `pnc_auth_config` | Generated at runtime from `files/sssd.conf.j2` via `tasks/generate_oud_config.yml` |
| OUD hostId account | Created by `amm-create-authn` (run manually on jumpbox) | Created automatically by the role, delegated to `lmrg34ja` |
| AD join | `pnc_join_ad` RPM `%post` | `tasks/join_ad.yml` via `adcli` |
| conf.d files | Shipped inside RPM | `files/50-pncad.conf.j2`, `55-pncad.conf.j2`, `60-pnc-OUD-AD.conf.j2` |
| krb5.conf | Shipped inside RPM | `files/krb5.conf.j2` |
| rbin scripts | `/usr/local/pnc/rbin/` from RPM | `files/rbin/` - same scripts, committed directly |
| login-access.conf | Populated by `pnc-run-discovery` in RPM `%post` | Same - `pnc-run-discovery` called in `tasks/configure_auth.yml` |
| Remove | `rpm -e` runs `%preun`/`%postun` | `dual_auth_lifecycle_action=leave_ad` |

## CLI usage

Environment is auto-detected from the 5th character of the hostname.
Override with `-e dual_auth_target_env=<rnd|uat|qa|prod>` if needed.

**New build / reconfigure (default)**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml
```

**Force rejoin AD**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_lifecycle_action=rejoin
```

**Leave AD (full decommission)**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_lifecycle_action=leave_ad
```

**Convert OUD+AD to AD-only**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_lifecycle_action=convert_ad_only
```

**Convert AD-only and add extra GSGu groups**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml \
  -e dual_auth_lifecycle_action=convert_ad_only \
  -e dual_auth_additional_gsgu_groups=GSLunxSP_SomeGroup
```

**Target a specific environment (override hostname detection)**
```bash
ansible-playbook -i hosts.txt playbooks/main.yml -e dual_auth_target_env=qa
```

## AAP Survey setup

| Question | Type | Variable | Default |
|---|---|---|---|
| Lifecycle action | Single-select | `dual_auth_lifecycle_action` | `configure` |
| OUD admin password (RND) | Password | `dual_auth_oud_admin_password_rnd` | |
| OUD admin password (UAT) | Password | `dual_auth_oud_admin_password_uat` | |
| OUD admin password (QA) | Password | `dual_auth_oud_admin_password_qa` | |
| OUD admin password (PROD) | Password | `dual_auth_oud_admin_password_prod` | |
| Target hosts | Textarea | `dynamic_hosts_input` | |

Lifecycle action choices: `configure`, `rejoin`, `leave_ad`, `convert_ad_only`, `recreate_keytab`, `recreate_sssd`

OUD admin passwords are only required for new builds (no existing sssd.conf).
Leave blank on reruns against already-configured hosts.
